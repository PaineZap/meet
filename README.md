# LaziMeet - Nền tảng họp trực tuyến GenZ (Phiên bản Fluid & Shooting Star)

LaziMeet là ứng dụng họp trực tuyến mang phong cách GenZ năng động, tích hợp:
- **Hiệu ứng sóng nước chuyển động mượt mà** ở background với bảng màu GenZ đặc trưng (Electric Purple, Hot Pink, Neon Cyan).
- **Hiệu ứng chữ lượn sóng (Wave animation)** cực cuốn hút tại tiêu đề chính.
- **Hiệu ứng tia sáng sao băng (Shooting star sparkles)** xuất hiện lung linh tại mọi điểm chạm/click trên màn hình.
- **Tương thích hoàn hảo (Responsive)** trên điện thoại, máy tính bảng và máy tính.
- **Tích hợp Jitsi Meet API**: Gọi video nhóm, chat và chia sẻ màn hình ổn định 100% trên GitHub Pages.
